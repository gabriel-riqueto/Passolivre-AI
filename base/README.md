# Base de conhecimento e proveniência

`trechos.json` contém 17 trechos: **10 simulados** (`S001`–`S010`) e **7 paráfrases de fontes públicas** (`G001`–`G007`). Cada item registra ID, título, natureza, referência, URL (quando há fonte pública) e aviso de licença. Os registros de ruas, nomes e status são **inteiramente fictícios**. Nenhum endereço real foi verificado.

Os resumos oficiais foram redigidos para a atividade e não reproduzem integralmente documentos de terceiros. Conferir a redação vigente das leis e decretos antes de uso fora da demonstração. Nenhuma norma ABNT foi copiada para a base; menções à ABNT no relatório são somente bibliográficas.

**Atualização da base:** revise as fontes, aumente a cobertura com materiais autorizados, ajuste a recuperação usando dados de desenvolvimento (sem contaminar o gabarito final), registre data de consulta e execute a avaliação novamente.

**Restrição:** IDs e fontes válidas não garantem fidelidade do texto gerado. A avaliação humana precisa verificar se cada afirmação está realmente suportada pelos trechos citados.
